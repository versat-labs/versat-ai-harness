# Inicio rápido

[English](quickstart.md) | [Português](quickstart.pt.md) | [Español](quickstart.es.md)

Para un desarrollador con acceso autorizado al repositorio que planifica su primer cambio, incluido un contribuidor externo cuando acceso y términos aplicables estén disponibles. Necesitas acceso al repositorio, proyecto local preparado y proveedor exacto del Harness con versat-sdd disponible. Completa [la preparación del entorno](guides/workspace-setup.es.md).

## Planificar un cambio pequeño

Usa un proyecto preparado desechable en este ejemplo. En un proyecto real, describe la historia verdadera y vincula su issue. Envía:

```text
Usa $versat-sdd para planificar welcome-message: agregar un mensaje breve y accesible de bienvenida a la página inicial existente. Muéstralo al cargar la página, siguiendo los idiomas del proyecto. Crea solo Proposal y Requirements; no implementes. Detente para revisión del Gate 1.
```

## Reconocer el resultado

Espera specs/changes/welcome-message/proposal.md y requirements.md, en inglés, con necesidad, alcance y escenarios observables de aceptación. Codex presenta la revisión conjunta para aprobación. Lee ambos y pide correcciones o aprueba la revisión presentada. Design y Tasks vienen después, tras los gates correspondientes; implementar requiere una solicitud explícita después de revisar Tasks.

## Si falta preparación

Si no se puede leer el proveedor o repositorio, vuelve a la preparación y resuelve acceso/versión antes de continuar. Si el proyecto no tiene página inicial, indica una pantalla existente o elige un comportamiento pequeño equivalente; no inventes funcionalidades implementadas. El contexto faltante debe generar una pregunta concreta, no una aprobación inventada.
