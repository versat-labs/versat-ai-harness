# Início rápido

[English](quickstart.md) | [Português](quickstart.pt.md) | [Español](quickstart.es.md)

Para um desenvolvedor com acesso autorizado ao repositório planejando sua primeira mudança, inclusive um contribuidor externo quando acesso e termos aplicáveis estiverem disponíveis. Você precisa de acesso ao repositório, projeto local preparado e provedor exato do Harness com versat-sdd disponível. Conclua [a preparação do ambiente](guides/workspace-setup.pt.md).

## Planejar uma mudança pequena

Use um projeto preparado descartável neste exemplo. Em um projeto real, descreva a história verdadeira e vincule sua issue. Envie:

```text
Use $versat-sdd para planejar welcome-message: adicionar uma mensagem curta e acessível de boas-vindas à página inicial existente. Exiba-a ao carregar a página, seguindo os idiomas do projeto. Crie somente Proposal e Requirements; não implemente. Pare para revisão do Gate 1.
```

## Reconhecer o resultado

Espere specs/changes/welcome-message/proposal.md e requirements.md, em inglês, com necessidade, escopo e cenários observáveis de aceitação. O Codex apresenta a revisão conjunta para aprovação. Leia ambos e solicite correções ou aprove a revisão apresentada. Design e Tasks vêm depois, após os gates correspondentes; a implementação requer pedido explícito após a revisão de Tasks.

## Se faltar preparação

Se não for possível ler o provedor ou repositório, volte à preparação e resolva acesso/versão antes de continuar. Se o projeto não tiver página inicial, informe uma tela existente ou escolha comportamento equivalente pequeno; não invente funcionalidades implementadas. Contexto ausente deve gerar uma pergunta objetiva, não uma aprovação inventada.
